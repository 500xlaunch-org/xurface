# Contributing to Xurface

Thank you for your interest. Xurface is early and moving fast.

## What we welcome

- Criticity rule packs (verb to criticity mappings, per domain)
- Framework and runtime integrations
- New transports for push and await (event mechanisms)
- Bug fixes, examples, and translations

## Before you start

- Open an issue to discuss anything non-trivial before sending a pull request.
- Keep changes focused and well described.
- The Discernment Event spec in `spec/` aims to stay small and implementable by
  any framework. Changes there deserve extra discussion.
