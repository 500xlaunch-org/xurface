# Examples

Runnable samples showing how agents route their critical actions through Xurface
Horizon.

- **[scenarios/](scenarios/)** - four real-life scenarios (a coding agent, a
  finance assistant, a support bot, an SRE agent), one per framework adapter.
  Each shows routine work flowing and the moments that matter held for a person.
  Start here.
- **[coding-agent-ts/](coding-agent-ts/)** - a minimal coding-agent integration.

Full example *Solutions* (their own repos): **BattleMate** (competitive
intelligence) and **FreeLeap** (freelance career) at
https://github.com/500xlaunch-org/battlemate and
https://github.com/500xlaunch-org/freeleap.
